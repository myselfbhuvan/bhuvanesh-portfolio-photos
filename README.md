# Bhuvanesh DevOps Project - Screenshots

This repository contains screenshots and evidence of my DevOps portfolio deployment project.

## Technologies Used

- GitHub
- Jenkins
- Docker
- GitHub Container Registry (GHCR)
- Terraform
- AWS EC2

## Project Architecture

GitHub → Jenkins → Docker Build → GHCR → AWS EC2 → Docker Container → Portfolio

Terraform is used to provision and manage the AWS infrastructure.
